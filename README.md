# NEXT Alumni: clickable prototype v4.2

Built from v4. Fictional data, nothing is saved (a reload resets everything).

Run: double-click `index.html`, or `python3 -m http.server 8000` in this folder and open http://localhost:8000.
Fonts load from Google Fonts, so be online for the exact look.

Sidebar bottom: switch between Member (Maya Okonkwo) and Admin (Nadia Morin) views.
Avatar menu: light/dark/system, Settings, sign out, "Restart as a first-time member" to replay sign-in + rules.
